# Visual Testing Strategy

This skill outlines how to visually verify that the UI matches the reference design.

1. Capture a screenshot of the local development server output.
2. Compare the screenshot side-by-side with the reference provided by the user.
3. Use developer tools to measure exact distances and compare with reference screenshots.
4. Ensure cross-browser consistency for modal overlays and sticky positioning.
