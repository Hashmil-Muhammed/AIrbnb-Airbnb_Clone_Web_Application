# Frontend Quality Skill

## Overview
This skill focuses on ensuring that frontend code is optimized, clean, and follows modern React and Next.js standards.

## Instructions
1. **Component Checks:** Ensure all components use semantic HTML5 elements (e.g., `<nav>`, `<article>`, `<section>`).
2. **Performance:** Verify that large images use optimization (like Next.js `<Image>`) or are properly lazy-loaded.
3. **Accessibility (a11y):** Check for `aria-labels` on icon-only buttons, valid `alt` tags on images, and sufficient color contrast.
4. **Code Cleanliness:** Ensure CSS Modules are used strictly and no inline styles are used unless absolutely necessary for dynamic layout calculations.

## Execution
Run this skill before finalizing any major UI component or prior to a deployment build to catch silent errors and performance bottlenecks.
