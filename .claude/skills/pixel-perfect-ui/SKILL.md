# Pixel-Perfect UI Skill

Use this skill when implementing UI sections to ensure that spacing and colors exactly match the reference.

## Checklist:
1. **Typography**: Are font weights exactly matched (e.g. bold for headers, standard for body text)?
2. **Spacing**: Use standard 8px grid multipliers. Compare paddings and margins for accuracy. 
3. **Icons**: Replace default icons with precise SVG paths to match the exact stroke width and size of the reference icons.
4. **Borders & Shadows**: Verify border radiuses (e.g., 12px on main cards) and box-shadows.
5. **Animations**: Test hover states (e.g., background tinting on image hover).
